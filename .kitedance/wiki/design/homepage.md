# Homepage Design Notes

## Hero Spacing

- The homepage slogan should appear closer to the top navigation than the earlier large vertical gap.
- Desktop `.hero` padding is `clamp(88px, 14vh, 128px) 0 72px`.
- Mobile `.hero` padding is `72px 0 56px`.

## File Mirroring

- Homepage content is kept in both `index.html` and `public/index.html`.
- Style/content changes for the homepage should remain synchronized across both files.
