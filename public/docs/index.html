KyteStore 使用文档

从源码编译 KyteStore，启动单机集群，再用 SDK 写入并读取一个 Blob。

编译安装 启动集群 使用 SDK

编译安装

在 Ubuntu 24.04 x86-64 上，从源码仓库或发行包的根目录安装编译工具、构建锁定版本的依赖，再安装 KyteStore。

sudo bash scripts/ci/install-ubuntu-deps.sh
export CMAKE_BUILD_PARALLEL_LEVEL=8
deps="$HOME/.local/kytestore-deps"
export KYTESTORE_PREFIX="$HOME/.local/kytestore"
bash scripts/ci/build-ut-deps.sh "$deps"
bash scripts/ci/build-linux.sh install "$deps" "$PWD/build-release" "$KYTESTORE_PREFIX"
"$KYTESTORE_PREFIX/bin/chunk_tools" --version

安装目录包含 bin/、lib/ 和 include/。首次编译依赖时使用空目录，并在使用这套安装期间保留该目录。

启动单机集群

准备可写的 MySQL 8.4 InnoDB 数据库，数据库账户需能初始化 RootServer 和 MetaServer 的表结构。启动服务前，在当前终端设置 KYTE_MYSQL_PASSWORD。

启动 RootServer 和 MetaServer

export PATH="$KYTESTORE_PREFIX/bin:$PATH"
export KYTE_MYSQL_HOST=127.0.0.1 KYTE_MYSQL_PORT=3306
export KYTE_MYSQL_DATABASE=kytestore KYTE_MYSQL_USER=kyte
export KYTE_RS_CLUSTER_ID=7401 KYTE_RS_ENDPOINT=127.0.0.1:9700
kytestore_rootserver schema apply
kytestore_rootserver serve --listen=127.0.0.1 --port=9700 &

RootServer 日志出现 “RootServer membership ready” 后，在同一终端启动 MetaServer。

kytestore_metaserver schema apply --rootserver-endpoints="$KYTE_RS_ENDPOINT"
kytestore_metaserver serve --rootserver-endpoints="$KYTE_RS_ENDPOINT" --port=9800 &

启动 ChunkServer 并注册磁盘

在支持 Direct I/O 的文件系统上新建磁盘镜像。仅在首次初始化时使用 --format-spdk，重启时复用数据、元数据和节点配置目录。

disk=$(mktemp -d "$HOME/kytestore-demo.XXXXXX")
export KYTE_DISK_DATA_DIR="$disk/data" KYTE_DISK_META_DIR="$disk/meta"
export KYTE_NODE_CONFIG_DIR="$disk/node"
mkdir -p "$KYTE_DISK_DATA_DIR" "$KYTE_DISK_META_DIR" "$KYTE_NODE_CONFIG_DIR"
fallocate -l 256M "$KYTE_DISK_DATA_DIR/device.img"
kytestore_chunkserver 19000 --rootserver-endpoints="$KYTE_RS_ENDPOINT" \
  --admin-port=19001 --format-spdk &

ChunkServer 日志出现 “registered node=”，且 MetaServer 日志出现 “MetaServer bound namespace_id=” 后，检查磁盘状态。

chunk_tools status --admin 127.0.0.1:19001

使用 SDK

客户端链接 KyteStore::sdk，并配置 RootServer 地址。创建 Blob 后按 ID 打开，追加写入数据，再按偏移读取并关闭句柄。

SDK 示例包含完整的 C11、C++17 程序与 CMake 配置。将示例文件和 CMakeLists.txt 放在一起，使用已安装的 SDK 编译。每次运行写入示例时请选择未使用过的 Blob 名称。

cmake -S . -B build -DCMAKE_PREFIX_PATH="$KYTESTORE_PREFIX"
cmake --build build
./build/blob_c "$KYTE_RS_ENDPOINT" examples/c-sync-001 sync
./build/blob_cpp "$KYTE_RS_ENDPOINT" examples/cpp-async-001 async
