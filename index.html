开源分布式 Blob 存储系统

面向数据库与湖仓，通过 C/C++ SDK 直连存储节点，支持追加写入和按偏移读取。

查看 C++ 示例 查看核心技术

C++ 读一个 Blob

同步读取

auto status = reader.PRead(
    offset, buffer, length,
    bytes_read);

异步读取

auto submitted = reader.PReadAsync(
    offset, buffer, length,
    bytes_read, done);

reader 是已打开的读句柄。异步提交成功后，保留缓冲区、bytes_read 和 BlobCompletion，直至 done.Done 回调返回最终状态。回调也可能在提交调用内执行。

接入场景

RocksDB 分布式存储

通过 RocksDB 文件系统适配层，将 SST 等数据映射为 Blob。读写由 SDK 直连存储节点，精简接入链路，替换这条链路上的 HDFS 存储依赖。

湖仓分布式存储

通过湖仓 FileIO 适配层直连 Blob，绕过 OSS 和 NAS 中转。启用 EC 后，校验分片在前台写入路径生成，EC UAW 用 redo 保护尚未写满的条带。

核心技术

按写入方式选择冗余策略

SDK 按 Blob 的分片布局直写 ChunkServer。不同模式决定每次追加需要写入哪些副本或分片。

Replica
在不同节点保存完整副本，支持任意长度追加。
EC AW
在前台写入数据和校验分片，追加必须按完整条带对齐。
EC UAW
支持任意长度追加，redo 保护未满条带，写满后生成正式校验分片。

同一协程推进请求直至完成

每块盘由独立的 ChunkServer 管理。Photon 协程在等待 I/O 时让出执行，磁盘返回后继续处理原请求。

  1. 接收请求
  2. 协程执行
  3. 等待 I/O 时让出执行
  4. 恢复协程并返回

符合条件的 I/O 复用 DMA 缓冲区

ChunkFS 校验页面 CRC，并在符合条件的直接 I/O 路径上复用 DMA 缓冲区，减少数据拷贝。SPDK blobstore 通过直接 AIO 访问磁盘镜像。

  1. ChunkFS 页面 I/O
  2. 复用 DMA 缓冲区
  3. 磁盘直接 I/O
