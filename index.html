开源分布式 Blob 存储系统

通过原生 C、C++ SDK，为数据库、数仓、对象存储和文件系统提供分布式存储底座。

使用文档 查看接入示例

核心特性

EiB 级数据存储

以 EiB 级集群为设计目标，通过增加服务器和磁盘扩展数据面。

开源

采用 AGPL-3.0。非商业场景可按许可证条款自行部署，商业使用同样遵循许可证条款。

前台 EC

按 Blob 选择多副本、对齐 EC 或支持字节粒度追加的非对齐 EC UAW。

原生 C SDK

通过 C11 接口封装其他语言客户端，也可以直接使用 C++17 SDK。

接入方式

传入已连接的 SDK 和一个新 Blob 名称。写句柄可以直接读回刚追加的数据。

C11

#include <kytestore/c/blob.h>

kytestore_blob_status_t round_trip(kytestore_blob_client_t *sdk,
                                  kytestore_blob_string_view_t name,
                                  char output[4], size_t *count) {
  kytestore_blob_create_options_t spec = {
    .capacity_bytes = 1U << 20, .blob_name = name,
    .replica_type = KYTESTORE_REPLICA, .replica_count = 1,
  };
  const kytestore_blob_completion_t blocking = {0};
  kytestore_blob_id_t id;
  kytestore_blob_handle_t *blob = NULL;
  kytestore_blob_append_result_t written;
  kytestore_blob_status_t status = kytestore_blob_create(sdk, spec, &id);
  if (!status.code)
    status = kytestore_blob_open(sdk, id, KYTESTORE_BLOB_APPEND, &blob);
  if (!status.code)
    status = kytestore_blob_append(blob, "Kyte", 4, &written, blocking);
  if (!status.code)
    status = kytestore_blob_pread(blob, written.offset, output, 4, count, blocking);
  if (blob) {
    kytestore_blob_status_t closed = kytestore_blob_close(blob);
    kytestore_blob_handle_release(blob);
    if (!status.code) status = closed;
  }
  return status;
}

C++17

#include <kytestore/sdk.h>

kytestore::Status round_trip(kytestore::Sdk& sdk, std::string_view name,
                             char (&output)[4], size_t& count) {
  kytestore::BlobCreateOptions spec{1U << 20, kytestore::ReplicaType::Replica, name};
  spec.replica_count = 1;
  kytestore::BlobId id{};
  auto status = sdk.CreateBlob(spec, id);
  if (!status.ok()) return status;

  kytestore::BlobHandle blob;
  status = sdk.OpenBlob(id, kytestore::BlobOpenMode::Append, blob);
  if (!status.ok()) return status;

  kytestore::BlobAppendResult written{};
  status = blob.Append("Kyte", written);
  if (status.ok()) status = blob.PRead(written.offset, output, sizeof(output), count);
  auto closed = blob.Close();
  return status.ok() ? closed : status;
}

Blob API
CreateOpenAppendPReadMultiPReadSyncClose

追加、单区间读取和多区间读取均支持同步与异步调用。

完整 API 列表
RTC 执行模型 ChunkServer 使用 Photon 协程将请求推进到完成。等待 I/O 时让出执行，完成后回到原协程，减少跨线程交接。
Zero Copy ChunkFS 在符合条件的路径上复用 DMA 缓冲区，减少数据拷贝、CPU 开销与内存带宽占用。
RDMA RDMA 可由网卡直接读写远端内存，降低 CPU 参与和网络时延，需要兼容的网卡和网络环境。
